# Zine Histórico ENEM ## Product Overview **The Pitch:** A radical departure from boring video lectures, transforming ENEM History prep into an interactive digital zine. Students master Brazilian and World history through illustrated short stories, pop-art visuals, and addictive mini-games. **For:** Gen Z Brazilian students tired of monotone teachers who crave visual stimulation and bite-sized, gamified learning. **Device:** Desktop (Primary), Responsive Web **Design Direction:** **Digital Pop-Art Manifesto.** Combines the raw energy of underground zines with 1960s Pop Art (Lichtenstein/Warhol). Think halftone patterns, mismatched typography, vibrant primary colors, and paper textures. It feels handmade, rebellious, and loud. **Inspired by:** *Persona 5* UI, *Spider-Man: Into the Spider-Verse* aesthetics, *Duolingo* gamification. --- ## Screens - **The Kiosk (Dashboard):** Main hub formatted like a newsstand; displays learning "Issues" (modules) and progress. - **The Issue (Lesson View):** Immersive, scrollable narrative reader for historical stories with parallax collage effects. - **The Arcade (Game Center):** Hub for fixation mini-games (Timeline Drag, Memory Match, Propaganda Quiz). - **Sticker Album (Profile):** User stats and achievements visualized as a collected sticker book. --- ## Key Flows **Flow: Completing a Lesson (Reading an Issue)** 1. User is on **The Kiosk** -> sees "Issue #4: Vargas Era" locked or available. 2. User clicks **Issue Cover** -> Screen transitions with a page-flip animation to **The Issue**. 3. User scrolls through illustrated text -> Interactive tooltips reveal historical context. 4. User reaches bottom -> Clicks "Desafio Rápido" (Quick Challenge). 5. **Result:** Completing the challenge unlocks a "Vargas" sticker for their album. ---
Design System ## Color Palette High-contrast, saturated colors typical of CMYK printing. - **Primary (Cyan):** `#00AEEF` - Action buttons, links, highlight borders. - **Secondary (Magenta):** `#EC008C` - Accents, error states, "hot" interactions. - **Tertiary (Yellow):** `#FFF200` - Background highlights, stickers, energetic fills. - **Key (Black):** `#1A1A1A` - Main text, thick comic outlines (never pure #000). - **Paper White:** `#F4F1EA` - Background (adds warmth/texture feel). - **Halftone Grey:** `#D1D3D4` - Muted elements, inactive states. ## Typography Loud, expressive, and hierarchical. - **Headings:** `Bangers`, 400, 48px-64px (Google Fonts) - Comic book sound effect style. - **Subheadings:** `Permanent Marker`, 400, 24px - Handwritten felt-tip feel. - **Body:** `Space Mono`, 400, 16px - Typewriter aesthetic for legibility but thematic fit. - **UI/Labels:** `Archivo Black`, 700, 14px - Heavy, industrial sans-serif for buttons. **Style Notes:** - **Borders:** Heavy, uneven black borders (3px-4px). - **Shadows:** Solid black hard shadows, offset by 4px (no blur). - **Texture:** Subtle SVG halftone noise overlay on backgrounds. ## Design Tokens ```css :root { --color-cyan: #00AEEF; --color-magenta: #EC008C; --color-yellow: #FFF200; --color-ink: #1A1A1A; --color-paper: #F4F1EA; --font-comic: 'Bangers', cursive; --font-marker: 'Permanent Marker', cursive; --font-typewriter: 'Space Mono', monospace; --font-ui: 'Archivo Black', sans-serif; --border-thick: 4px solid #1A1A1A; --border-thin: 2px solid #1A1A1A; --shadow-hard: 4px 4px 0px #1A1A1A; --shadow-hover: 6px 6px 0px #EC008C; } ```

Screen Specifications ### The Kiosk (Dashboard) **Purpose:** Navigation hub. Presents historical eras as comic book "Issues" on a rack. **Layout:** - **Top Bar:** Logo (Left), "XP" Counter (Right), Avatar (Right). - **Main Stage:** Horizontal scrollable "Magazine Rack" centered vertically. - **Bottom Bar:** Quick navigation (Arcade, Album, Settings). **Key Elements:** - **Magazine Rack:** CSS Grid. Holds "Issue Cards." Background has a subtle wood texture pattern. - **Issue Card (Module):** - 280px x 400px. - Looks like a comic cover. - **Top:** "VOL. 1" badge. - **Center:** High-contrast historical collage (e.g., Napoleon riding a skateboard). - **Bottom:** Title "ERA NAPOLEÔNICA" in `Bangers`. - **State overlay:** A padlock icon if locked; a "Lido" stamp if completed. - **Streak Flame:** Top right. Animated SVG flame icon with number. **States:** - **Locked:** Card is greyscale with halftone overlay. - **New:** "LANÇAMENTO" (New Release) sticker on top corner. **Interactions:** - **Hover Card:** Card tilts 5deg, shadow grows to `--shadow-hover`, background color shifts to Yellow. - **Click Card:** Zoom-in transition to **The Issue** screen. --- ### The Issue (Lesson View) **Purpose:** The core learning experience. Reading content formatted as a visual story. **Layout:** Single column, centered content (max-width 800px). Left/Right gutters contain "margin notes." **Key Elements:** - **Header Image:** Full-width hero collage with parallax scroll effect. - **Narrative Text:** `Space Mono` font. Short paragraphs. - **Pull Quotes:** Massive `Bangers` font, rotated -2deg, yellow highlighter background. - **"Did You Know?" Bubbles:** Pop-up speech bubbles in the margins with trivia. - **Image Carousel:** Polaroid-style framed images of historical artifacts. Users click arrows to flip through. **Components:** - **Progress Bar:** Sticky top. Fills with Magenta ink as user scrolls. - **Next/Prev Buttons:** Fixed bottom corners. Styled like comic book "Turn Page" triangles. **Interactions:** - **Highlighting:** Selecting text triggers a "Marker" animation (yellow background sweep). --- ### The Arcade (Game Center) **Purpose:** Gamified revision. **Layout:** Grid of "Game Cartridges" (Retro NES style aesthetic). **Key Elements:** - **Game Cartridge:** - Rectangular, grey plastic texture. - Label art matches the game type. - Title: "MEMÓRIA DA DITADURA" or "QUIZ INDUSTRIAL". - **Leaderboard:** Sidebar on the right. Styled like a wrinkled high-score paper list tacked to a wall. **States:** - **Active Game:** Modal overlay takes over screen (80% width). - **Game Over:** Screen shakes, giant "FIM DE JOGO" text in red `Bangers` font. **Components:** - **Cartridge:** 200px x 240px. - **Play Button:** Large, blinking green pixel-art button. --- ### Sticker Album (Profile) **Purpose:** Visualizing progress and achievements. **Layout:** A grid representing an open book. Two pages visible side-by-side. **Key Elements:** - **The Album Pages:** - Background texture: Crumpled paper. - Grid of faint dotted outlines (placeholders for stickers). - **The Stickers:** - Die-cut PNGs with white borders and drop shadows. - Historical figures with punk edits (e.g., Dom Pedro II with sunglasses). - Rare stickers have a CSS holographic foil effect (gradient overlay). - **Stats Block:** - Bottom left page. - "Títulos Lidos: 12", "XP Total: 4500". - Font: `Permanent Marker` (handwritten look). **Interactions:** - **Hover Sticker:** Scale up 1.1x, z-index boost. - **Empty Slot:** Tooltip says "Complete [Module Name] to unlock".

Build Guide **Stack:** HTML5, Tailwind CSS v3 (with custom config for colors/fonts), Alpine.js (for lightweight interactions/state). **Build Order:** 1. **Design System Setup:** Configure `tailwind.config.js` with `Bangers`, `Space Mono`, custom colors, and the hard-shadow utility classes. This defines the vibe immediately. 2. **The Issue (Lesson View):** This is the core value. Build the typography, the parallax images, and the reading experience first. 3. **The Kiosk:** Build the navigation and grid system. 4. **The Arcade:** Implement one simple game logic (Quiz) to test the modal system. 5. **Sticker Album:** Tie the data together visually.
